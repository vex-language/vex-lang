module shapes // import "shapes"

    Flat shapes and their areas.

    tells them apart.

--- shapes.Circle
struct Circle: Shape

    A circle, centred anywhere.

    - The area grows with the square of [radius].
    - Its [kind] is always [Kind.round].

    ```
    let c = Circle(radius: 2.0)
    println(c.area())
    ```

    radius: float
        The distance from the centre to the edge.

    let name: string = "circle"

    fn area() -> float
        Returns **pi** times the radius squared, see [pi].

    get kind -> Kind

    static fn unit() -> Circle
        Returns a circle of [radius] 1.
